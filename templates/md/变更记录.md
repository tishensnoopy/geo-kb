# 变更记录

> 知识库每次改动都留痕。写清改了什么、为什么、谁改的。
> 这样客户回头能问「这条是什么时候变的、为什么变」。

## 记录格式

```markdown
### 2026-XX-XX · <改动类型>

- **事实**：<条目名>
- **变更前**：
- **变更后**：
- **变更类型**：新增入库 / 内容修正 / 证据补挂 / 冲突修正 / 周期到期复审 / 删除下线
- **触发原因**：
- **操作人**：
```
