# 联网检索与来源分级

检索的目的是**发现客户不知道自己被怎么说的**，不是替客户确认事实。客户没确认过的外部说法，永远不能变成事实。

## 检索什么

### 企业自己的说法

- 官网：首页、关于我们、价格、服务、资质、常见问题
- 官方账号与近期发布内容
- 地图与点评平台（地址、营业时间、评分、常见评价）

客户经常不知道自己官网写了什么。这一步经常能发现**官网说得比实际能力强**的情况。

### 第三方怎么说

- 行业平台、行业媒体的描述
- 百科类词条
- 媒体报道（含时间，只用近期资料）

### 竞争与市场

- 2 到 5 个真正可比的对手（能争夺同一次购买的那些）
- 对手的公开营销材料：排行稿、推荐稿、对比稿
- 客户常被提到的替代方案，包括「不买」「用现有工具凑合」

龙头企业可以解释背景，但没在争夺同一批客户就不能当直接对手。

## 来源分级

每条都照实标，不要一律写「官方」：

| 级别 | 来源 | 能用来做什么 |
|---|---|---|
| A | 官网、政府、监管、企业公告 | 可以当事实依据 |
| A | 主流媒体、财报、企业披露 | 可以当事实依据 |
| B | 行业数据机构 | 可以引用，要写清口径 |
| C | 招商平台、自媒体、短视频招商内容 | **只能当营销痕迹，不能当事实依据** |

C 级内容不能用来证明费用、门店数、回本周期、市场份额。这条不能松。

## 看营销痕迹

要找的是**对手在影响客户哪个选择**。

组合搜索：`业务或购买任务 + 地区 + 选型/哪家好`、`竞品名 + 排行/十大/评测`。找到疑似通稿后，看独特句段、完整标题、联系方式。

痕迹特征：

- 多篇稿件段落结构雷同
- 品牌出现顺序固定
- 统一评分但无测评方法
- 相同联系方式或推广标识

多篇重复 →可以说「疑似系统化营销或分发」，并保留转载、SEO、公关等其他解释。

**不能得出的结论**：

- 内容多 ≠ 竞争力强
- 内容重复 ≠ 被AI 降权
- 推广痕迹 ≠ 企业委托或付费
- 没找到营销稿 ≠ 企业没做营销
- 品牌在榜单上 ≠ AI 会推荐它

## 每条要记什么

```markdown
### 条目N

- **来源类型**：官网 / 第三方平台 / 媒体报道 / 地图点评 / 竞品材料
- **来源名称**：
- **来源分级**：A官方 / A媒体 / B行业数据 / C自媒体或营销痕迹
- **日期**：2026-XX-XX（没有就写「未标注」）
- **链接**：https://...
- **外部说法原文**：

  （照抄原文，不改写、不概括、不加判断）

- **客户是否确认**：待确认
- **冲突说明**：
```

**原文必须照抄。** 概括会把不确定性抹掉，而不确定性恰恰是判断的关键。

## 对账规则

拿到客户面前时逐条问「认不认」，四种结果：

| 客户回答 | 怎么处理 |
|---|---|
| 认，并给了更准的说法 | 写进事实库，用客户的版本 |
| 认，但说要补证据 | 写进事实库，标记待补证据，列入更新待办 |
| 不认 | 标冲突，问清客户认为正确的是什么 |
| 也不知道 | 标待确认，列入更新待办，不擅自改写 |

对账中发现的**缺口**（客户确认重要、但手上没材料）单独记录，这是下一步补资料的重点。

## 数字要核对口径

每个数字都要问：说的是哪一年、哪个业务、哪个型号或套餐、什么条件下。

- 报告名称、编号、面积、资质**不证明**实际能力
- 面积不证明可用容量、交付质量或转化率
- 零散评论能发现客户疑问，不能用来给整个行业排优劣

口径对不上的数字，删掉或标为待核对。宁可少一个数字，不要多一个假数字。

## 停下来确认的情况

出现下列任一情况，**先停下来用一句话向客户确认主体**（工商全称与官网），确认后再继续：

- 客户给的名字与某个知名品牌同音或近似
- 公开检索找不到官网，事实全部来自第三方平台
- 检索到的主体、地区或业务与客户描述对不上

搜不到不代表不存在，但也绝不能凭猜测填库。
